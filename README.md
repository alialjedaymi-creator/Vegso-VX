# منظومة الخير للمعدات — نسخة مبدئية

نسخة MVP محلية تتضمن خادم Express بسيط وواجهة HTML/JS. هدفها أن تعطيك قاعدة قابلة للتوسيع.

تشغيل محلي (نقطة البداية):

1. انتقل إلى مجلد `server` وانصّب التبعيات:

```powershell
cd "c:\Users\الخير\.gemini\antigravity-ide\scratch\clinic-system\server"
npm install
npm start
```

2. افتح المتصفح على:

```
http://localhost:3001/
```

ملاحظات مهمة:
- الحسابات الافتراضية وكلمات المرور الخاصة بها:
  - **مدير (`admin`)**: كلمة المرور هي `101010`
  - **مشرف (`supervisor`)**: كلمة المرور هي `202020`
  - **موظف (`employee`)**: كلمة المرور هي `1234`
- يجب تشغيل الخادم أولاً بالانتقال إلى مجلد `server` وتشغيل `node index.js` أو `npm.cmd start` ثم الدخول إلى `http://localhost:3001/` للاستفادة من قاعدة البيانات.
- إذا قمت بفتح `index.html` في المجلد الرئيسي مباشرة بالمتصفح، ستعمل المنظومة في وضع "التخزين المحلي المؤقت" (Local Storage) بدون قاعدة البيانات.

توسعات مقترحة لاحقًا: واجهة React، نظام مصادقة كامل، تصدير تقارير، تحسين واجهة الطباعة، نشر سحابي.
